# Referência de cores — WL Negócios & Seguros

## Escopo

A referência para este projeto são **somente as cores** do site [WL Negócios & Seguros](https://wlnegocioseseguros.com.br/). O layout, a estrutura das páginas, os componentes e as fontes do site atual **não são referências** e não devem ser reproduzidos. O novo design deve definir esses elementos de forma independente, com uma apresentação atual, clara e acessível.

## Paleta observada

Valores obtidos dos estilos aplicados na página inicial consultada em 5 de novembro de 2026. Os usos abaixo descrevem onde as cores foram encontradas, não uma obrigação de repetir o mesmo arranjo.

| Cor | Hexadecimal | Uso observado no site de referência |
| --- | --- | --- |
| Verde claro | `#C8DFBE` | Fundo de navegação e rodapé |
| Verde suave | `#758C6E` | Fundo de botões |
| Marrom escuro | `#6B4A30` | Texto e detalhes |
| Marrom médio | `#B07A51` | Títulos |
| Branco | `#FFFFFF` | Fundos e texto sobre algumas áreas coloridas |

## Aplicação no novo projeto

- Use a paleta acima como ponto de partida para a identidade visual; não considere o design existente como modelo de composição.
- Defina tipografia, espaçamento, hierarquia, navegação e componentes especificamente para o novo projeto.
- Confira o contraste de cada combinação antes de utilizá-la, especialmente texto branco sobre verde claro ou verde suave e texto marrom médio sobre branco. Ajustes de tonalidade podem ser necessários para garantir legibilidade e acessibilidade.
- Cores de imagens, efeitos de transparência e estados de interação não estão definidos aqui como tokens oficiais.
